評估日期： 2026-10-30（最新修復後再次驗證）

測試方法： 白盒程式碼審計 + 黑盒只讀 API 探測 + 真實瀏覽器驗證

一、評估結論

整體風險等級：低（Low）

原報告中的四個嚴重漏洞（資料庫主表外洩、儲存桶匿名寫入、邊緣函式無鑑權、後台網域錯字）皆已封堵。目前僅餘架構性限制（TLS 版本）與選配性強化（bcrypt 強度），未發現可被利用的資料外洩或系統入侵路徑。

所有測試均為非破壞性： 僅進行只讀探測，未刪除、未修改任何真實資料，未進行壓測、未爆破、未針對 Supabase 平台本身攻擊。

七、建議後續動作（依優先順序）

必做（若有自訂網域）

  • 關閉 TLS 1.0/1.1：綁定自訂網域後，於 Cloudflare Dashboard → SSL/TLS → Edge Certificates → Minimum TLS Version → TLS 1.2。

可選（低優先度）

  • 提升 bcrypt cost：貼出 submit_qsl_request 的 prosrc，協助將 gen_salt('bf', 6) 改為 gen_salt('bf', 10)。舊雜湊無法自動轉換，新設定的密碼才會用 cost=10。
  • 清測試資料：
    • 資料庫：DELETE FROM public.requests WHERE record_id IN (21, 193, 194) AND applicant_name LIKE 'SECAUDIT%';
    • Storage：刪除 SECAUDIT_probe.txt、SECAUDIT_p2.txt、SECAUDIT_p3.txt、SECAUDIT_snap.txt
